# Gestor-de-Eventos1

## 1. Descripción del proyecto
Este repositorio contiene la documentación completa para el diseño del "Gestor de Eventos", una aplicación de consola desarrollada como simulación de un proyecto real de software para la asignatura de Entornos de Desarrollo. 

La aplicación está pensada para permitir a un usuario administrador gestionar de forma centralizada eventos, usuarios e inscripciones mediante una interfaz de consola clara, asegurando el control de aforos y la persistencia lógica del sistema.

## 3. Índice de documentos
A continuación se facilitan los enlaces directos a los archivos de documentación que dan forma al diseño del sistema:

* [Documento de Requisitos (requisitos.md)](requisitos.md): Detalla la descripción general, las funcionalidades de la aplicación, los tipos de usuarios y los casos de uso principales.
* [Diseño del Sistema (diseno.md)](diseno.md): Contiene la estructura de las clases principales (GestorEventos, Evento, Usuario), sus relaciones y el diagrama de clases correspondiente.
* [Manual de Usuario (manual.md)](manual.md): Guía explicativa con el funcionamiento del menú principal de consola y ejemplos prácticos de uso.
* [Planificación del Trabajo (planificacion.md)](planificacion.md): Muestra el reparto de tareas entre los componentes del grupo, las fases del proyecto y el cronograma seguido.

## 4. Resumen del trabajo y uso de GitHub
El desarrollo de este proyecto se ha realizado siguiendo una metodología colaborativa real utilizando GitHub como herramienta de control de versiones. 

Para asegurar la estabilidad del documento final, se prohibió trabajar directamente sobre la rama principal (`main`), aplicando el flujo de trabajo por ramas. Cada integrante desarrolló su documentación en una rama independiente (`feature-requisitos`, `feature-diseno`, `feature-manual` y `feature-planificacion`) y se integraron los cambios mediante Pull Requests supervisadas y revisadas por los compañeros del equipo.
