# Planificación del Trabajo - Gestor de Eventos

## 1\. Reparto de Tareas

* **Desarrollador A:** Configuración del entorno y Base de Datos.
* **Desarrollador B:** Interfaz de usuario (Frontend).
* **Desarrollador C:** Lógica de negocio y API (Backend).

## 2\. Fases del Proyecto

1. **Fase 1: Análisis:** Definición de requisitos y diseño de esquemas.
2. **Fase 2: Desarrollo:** Codificación de las funcionalidades principales.
3. **Fase 3: Pruebas:** Testing de errores y correcciones.
4. **Fase 4: Despliegue:** Preparación para entrega final.

## 3\. Cronograma Simple

* **Semana 1:** Creación de la estructura y diseño.
* **Semana 2:** Desarrollo del backend y conexión con base de datos.
* **Semana 3:** Pulido de interfaz y entrega.
